# Arise — marketing site

Static single-page landing site for the Arise mission alarm. Served via GitHub Pages.

- Source of record lives in the app repo under `web/`; this repo is the published copy.
- **Before launch:** replace the placeholder `href="#"` on the App Store / Google Play
  badges in `index.html` with the real store listing URLs.
- **Custom domain (`risen-alarm.com`):** not wired. To attach, add a `CNAME` file
  containing `risen-alarm.com` and point DNS at GitHub Pages. Do NOT add the CNAME file
  until DNS is configured, or the `github.io` URL will break.
